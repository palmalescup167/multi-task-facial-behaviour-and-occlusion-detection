## 🧪 How It Works (Simple Explanation)

Behind the scenes, the application uses something called a **neural network** – a type of artificial intelligence that learns from examples. This particular AI was trained on thousands of face images, so it knows what human faces look like and can recognize emotions and obstacles.

- **Emotion Recognition** uses a "ResNet‑18 with CBAM" model. This is a highly accurate algorithm that understands subtle changes in your facial muscles.
- **Occlusion Detection** uses MediaPipe FaceMesh, which maps 468 points on your face in real time. If those points are not visible due to an object, it flags it.
- **Face Finding** uses MTCNN, which quickly finds the face in every video frame before analyzing it.

All three parts work together in real‑time to give you instant results. You can see everything happening live on your screen.
